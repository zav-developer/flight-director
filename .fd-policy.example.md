# Flight Director policy

Place a customized copy at `.fd/policy.md`.
The `.fd` directory stays local and is ignored by Git.

## Defaults

- Isolation: shared checkout
- Delivery: local
- Validation: independent review
- Approval: before destructive actions, push, and merge
- Evidence: changed files, targeted validation, and unresolved findings

## Escalation

Use a worktree when changes overlap, the user is editing concurrently, or rollback risk is high.
Use a pull request for public contributions, risky changes, or asynchronous review.
Use no-mistakes only when the task warrants its full PR pipeline.
